# Purdue-Meal-Scanner
An application that pulls data and shows information about current meals available at Purdue Dining halls.

Project Goal: 
Make a better organized system that shows everything available at the time rather than needing to move through menus. Also allow for favoriting specific meals and knowing when they are available.

Project Schedule:
1. Set up repo and workspace
2. Access Purdue Dining data and output list of meals
3. Output list of meals based on dining courts and times
4. Set up favoriting to favorite specific meals
5. Output favorited meals that are available alongside general information.
6. Set up better organization and viewing for user.
7. Final bug fixes

Project MVP:
Parse and sort JSON data from Purdue Dining API. Sort data and output into a list for current time.

Project Tech Stack:
Java
org.json (getJSONObject, getJSONArray), java.time
VS Code
Purdue Dining API
